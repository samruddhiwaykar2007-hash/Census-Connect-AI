# 🇮🇳 CensusConnect AI

A **GenAI-powered multilingual digital Census companion** built for the **Census 2027 & Digital Enumeration** challenge at **PromptWars × ADYPU**, organized by **Hack2skill**.

CensusConnect AI makes Census information simple, accessible, and easy to understand, especially for digitally inexperienced users.

## ✨ Features

- 🤖 Aadya AI Census Guide
- 🌐 Multilingual Support — English, Hindi & Marathi
- 🔊 Voice Assistance in the selected language
- 🏠 Simple explanation of the two Census phases
- 📅 State-wise Census Schedule
- 📝 Step-by-step Self-Enumeration Guide
- 🔒 Privacy & Digital Safety Awareness
- 🔍 Misinformation & Scam Message Checker
- 📊 Interactive Census Data Visualization

## 🛠️ Tech Stack

**React • Vite • JavaScript • Supabase • PostgreSQL • Web Speech API • Recharts**
